# Exploratory Data Analysis (EDA) Project

## Project Summary

This Exploratory Data Analysis (EDA) project focused on understanding customer purchasing behavior, product performance, sales trends, and operational efficiency within an e-commerce environment. The primary objective of the analysis is to transform raw transactional data into meaningful business insights that support data-driven decision-making for sales, marketing, and operational teams.

The analysis explores key performance indicators such as revenue, order volume, customer activity, purchase rates, product performance, payment preferences, discount usage, and fulfillment trends. Through statistical summaries and visualizations, the project identifies patterns in customer behavior, highlights top-performing products, evaluates sales performance across locations and time periods, and examines factors that influence purchasing decisions.

## Project file Structure

The repository is organized around the following key files:

**[Cleaned_Dataset](Cleaned_Dataset.xlsx/)**
- Contains the cleaned and structured dataset prepared during a previous **[Project_1](Project_1/)** data cleaning and preparation process. This dataset serves as the primary data source for all exploratory analyses and visualizations.

**[Data_analytics_P2](Data_analytics_P2.pdf/)**
- Provides the project requirements, business questions, and analytical tasks that define the scope and objectives of the EDA. It acts as the guiding framework for the analysis.

**[eda_notebook](eda_notebook.ipynd/)**
- A Python notebook where the complete EDA process is documented. It includes data exploration, feature engineering, aggregation, statistical analysis, and visualization steps used to generate insights from the dataset.

**[eda_with_excel](eda_with_excel.xlsx/)**
- An interactive Excel dashboard developed for business users and stakeholders. The dashboard presents key metrics and visual summaries in an accessible format, allowing users to explore sales performance and answer business questions without requiring programming knowledge.

## Key Outcomes

The project delivers insights into:

* Revenue and sales performance over time.
* Weekly and monthly purchasing trends.
* Product demand and revenue contribution.
* Customer acquisition and payment preferences.
* Customer spending behavior and purchasing patterns.
* Order fulfillment and operational performance.
* The impact of discounts and promotions on sales.

By combining Python-based analysis with an interactive Excel dashboard, this project provides both technical and business-focused perspectives, enabling stakeholders to better understand performance drivers and identify opportunities for growth and optimization.
